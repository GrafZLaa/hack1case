# ПАСПОРТ.ЦИФ — Система оцифровки паспортов оборудования
## Хакатон РТУ МИРЭА 2026 · Задача 1

### Возможности
- **OCR через Claude Vision** — распознаёт паспорта в произвольном формате (одиночные, групповые, без номера)
- **Редактирование** — все поля корректируются вручную
- **Генерация штрихкодов** Code 128
- **Экспорт в Excel** — 3 листа: паспорта, перечень шкафа, характеристики
- **Реестр** — все обработанные документы хранятся локально

### Установка и запуск

```bash
# 1. Перейти в папку
cd passport_system

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Задать API-ключ Anthropic
export ANTHROPIC_API_KEY=sk-ant-...   # Linux/Mac
set ANTHROPIC_API_KEY=sk-ant-...      # Windows

# 4. Запустить
python app.py

# 5. Открыть в браузере
http://localhost:5000
```

### Поддерживаемые типы документов
| Тип | Пример |
|-----|--------|
| Паспорт без заводского номера | КЕАЗ ОрбиД PA10/16-502 |
| Паспорт с одним номером | ТРЭИ Мастер-модуль M1201E |
| Групповой паспорт | TECON ТСС 8L (16 номеров) |
| Перечень документации шкафа | Шкаф №10 САУ ГПА |

### Архитектура
- **Backend**: Python Flask
- **OCR**: Anthropic Claude claude-opus-4-5 (Vision)
- **Штрихкоды**: python-barcode (Code 128)
- **Экспорт**: openpyxl
- **Frontend**: HTML/CSS/JS (без фреймворков)

### Требования
- Python 3.10+
- ANTHROPIC_API_KEY
- Интернет для Claude API (или локальный ollama — см. настройки)
